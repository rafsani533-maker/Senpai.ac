# senpai.ac

Futuristic anime/cyber profile website for **senpai.ac**.

## Files

- `index.html` — main website. JavaScript is already included inside this file.
- `style.css` — complete styling and responsive layout.
- `background.jpeg` — the anime image used as the website background.
- `README.md` — this setup guide.

## GitHub Pages setup

1. Upload `index.html`, `style.css`, and `background.jpeg` to the repository.
2. Make sure all three files are in the same folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
